## 🚀 Fitur Unggulan

- **🍭 Candy & Claymorphism UI**: Desain bertema pastel hangat (*Cotton Candy Pink, Honey Yellow, Sky Mint, Soft Lavender*) dengan sudut membulat ramah.
- **✨ Interactive Background WebGL**: Latar partikel Three.js melayang lembut merespons pergerakan kursor mouse (*parallax effect*).
- **⇄ Before/After Clay Comparison Slider**: Slider interaktif di setiap modal proyek untuk membandingkan render warna vs model clay breakdown asli dari Blender.
- **🔊 Kawaii Micro-interactions**: Efek audio synthesizer gelembung lembut saat interaksi tombol.
- **🛡️ Serverless Commission API (`/api/commission`)**: Backend terintegrasi untuk pemesanan komisi yang aman dengan sanitasi data.
- **☕ Dukungan Komunitas (Trakteer)**: Integrasi langsung tautan donasi/traktir [teer.id/ansel-caprico-ubqyc](https://teer.id/ansel-caprico-ubqyc).

---

## 🛠️ Tech Stack

- **Frontend**: Semantic HTML5, Vanilla CSS3 (Custom Design System & Keyframe Animations), Modular JavaScript (ES6+).
- **3D & WebGL**: Three.js (r128).
- **Backend / Serverless**: Node.js Serverless Function on Vercel (`/api/commission.js`).
- **3D Modeling & Rendering**: Blender 4.2 / 5.2 (Subdivision Surface Modeling, Cycles, EEVEE).
- **Deployment Platform**: Vercel.
